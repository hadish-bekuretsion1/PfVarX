`ne_110m_countries.geojson`: Natural Earth 1:110m Admin 0 countries (public domain,
https://www.naturalearthdata.com), extracted from the conda-forge package
`r-rnaturalearthdata` 1.0.0 (`countries110`) with columns name, iso_a3, continent and
coordinates rounded to 3 decimals. Used offline by DA007 (point-in-country validation)
and by the dashboard map. Country borders at this scale are approximate.
