    Reference Preparation
    

    If the sample sheet is missing, this step creates a template. Register samples and run it again. Preparation rechecks input validity and writes derived reference files under prepared/reference/. It builds the FASTA indexes and sequence dictionary, and adds BWA-MEM2 indexes for FASTQ entry.
