PfVarX configuration

Each tab runs the same step as its terminal command, shown on the tab. You can switch between this page and the terminal at any stage.

Terminal equivalent: edit the YAML files in config/, then ./pfvarx input-directories. A schema-3 configuration is migrated on save, as ./pfvarx config-migrate --apply does.

The path is relative to your study workspace. The folder is created when you save.

Input folders and expected contents

After saving, supply or register the files listed for your configuration.

    Reference Preparation
    

    Terminal equivalent: ./pfvarx prepare-reference.
    

    For FASTQ input, PfVarX creates a missing sample sheet from paired reads during validation or preparation. Review inferred sample and library IDs before analysis. For BAM input, preparation creates a blank template if needed. Preparation rechecks input validity and writes derived reference files under inputs/reference/prepared/. It builds the FASTA indexes and sequence dictionary, and adds BWA-MEM2 indexes for FASTQ entry.
    


    

    

    

    Workflow Readiness Checks
    

    Terminal equivalent: ./pfvarx workflow-readiness-checks.
    


    

    

    

    

    Workflow Check and Run
    

    Terminal equivalent: ./pfvarx workflow-check and ./pfvarx workflow-run.
    

    The check plans the workflow without creating outputs. The run repeats the check and, only if it passes, starts a new analysis. A run continues in the background if you close this page; reopen this tab to see its status.
